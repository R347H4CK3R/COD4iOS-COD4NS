# Project instructions

Preserve original COD4 and MW3 installations and user-edited mod files.
For each personal IPA delivered to this user, bundle all locally converted MW3 FF/IWD dependencies required by enabled features using tools/bundle-mw3-assets.py. See docs/MW3-ASSET-PACKAGING.md. Do not commit retail assets or upload them into public GitHub build artifacts. Deliver the locally bundled personal IPA and corresponding source. Do not present research snapshots as playable maps.

This personal app exposes Survival only. Campaign and COD4 multiplayer remain preserved source, not selectable modes. Add MW3 bot multiplayer only after genuine IW5 multiplayer/bot behavior works in the iOS runtime; PC Bot Warfare support alone is not proof of iOS support. Frontend and loading presentation should follow MW3 Spec Ops styling, and stock COD4 frontend must not appear in Survival.
