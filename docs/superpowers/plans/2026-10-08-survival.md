# Survival Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Integrate the existing Survival rules into a selectable iOS game mode.
**Architecture:** Portable session and identity tracking feed a single-player
actor adapter. A synchronized bridge connects native HUD/shop actions to the
engine thread. An isolated GSC level entry supplies shared map setup.
**Tech Stack:** C++17/20, Objective-C++/UIKit, COD4 GSC, CMake, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-10-08-survival-design.md

## Global Constraints
- Preserve retail main, zone, localization.txt, profiles and saves.
- iOS 17+, arm64, unsigned output, no retail data packaged.
- Actor cap 12; waves cap 120; ammo 250, armor 500, rifle 750.
- Native execution authorized in chat; no further design approval needed.

## Review Focus
- Entity slot reuse and duplicate death must not produce duplicate rewards.
- Failed item grants cannot spend credits or grant an item twice.
- Shop close must release held gameplay buttons and freeze its countdown.
- Missing spawners and inaccessible scripts must fail visibly.
- Legacy and corrupt saved modes must route to a valid engine.
